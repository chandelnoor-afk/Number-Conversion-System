# Number Conversion System

## About the Project

The **Number Conversion System** is a web-based mini project designed to demonstrate number system conversions and binary arithmetic algorithms through an interactive interface. It helps users understand how computer arithmetic works by performing calculations and displaying step-by-step algorithm explanations.

## Features

### 1. Number System Conversions
- Decimal to Binary
- Binary to Decimal
- Decimal to Hexadecimal
- Hexadecimal to Decimal
- Conversion results with explanations

### 2. Booth's Multiplication Algorithm
- Perform multiplication using decimal or binary inputs.
- Calculate the multiplication result.
- Understand the working of Booth's multiplication algorithm through explanations.

### 3. Restoring Division Algorithm
- Perform binary division using the restoring division method.
- View the calculated result and algorithm explanation.

### 4. Non-Restoring Division Algorithm
- Perform division using the non-restoring division method.
- Learn how the algorithm handles binary arithmetic operations.

### 5. Interactive User Interface
- Simple homepage with navigation to different algorithms.
- Separate pages for number conversion, multiplication, and division.
- Interactive calculators for performing calculations.

## Technologies Used

- **HTML5** – Structure of the web pages
- **CSS3** – Styling and layout
- **JavaScript** – Calculations, algorithm implementation, and user interactions

## How to Run the Project

1. Download or clone this repository.
2. Extract the project files if downloaded as a ZIP archive.
3. Open the project folder.
4. Open `frontpage.html` in any modern web browser.
5. Select the desired conversion or arithmetic algorithm and enter the required values.

No server setup is required for the basic HTML, CSS, and JavaScript interface.
